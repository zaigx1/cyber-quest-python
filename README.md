# cyber-quest-python
A beginner friendly Python terminal game featuring number guessing, cybersecurity quizzes, and phishing awareness challenges.

Features
Number guessing challenge
Basic cybersecurity quiz
Phishing awareness challenge
Score and ranking system

Requirements
Python 3
No external libraries required

How to Run
python cyber_quest.py

On Windows, you can also use:
py cyber_quest.py

Purpose
This project was created to practice Python programming fundamentals and explore basic cybersecurity concepts.
